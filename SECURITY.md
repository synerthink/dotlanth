# Security Policy

## Project Status

Dotlanth is currently in **pre-production** (milestone 26.1.0-alpha.1). This project does not claim any security compliance certifications (such as ISO 27001, SOC 2, etc.) at this stage.

## Reporting Vulnerabilities

If you discover a security vulnerability in Dotlanth, please report it by opening a private security advisory on the GitHub repository:

1. Navigate to the [Security tab](https://github.com/synerthink/dotlanth/security/advisories)
2. Click "Report a vulnerability"
3. Provide a clear description, steps to reproduce, and affected versions

Do not disclose security issues in public issues or pull requests.

## Response Timeline (Pre-Production)

- **Acknowledgment**: Within 7 days of report
- **Initial assessment**: Within 14 days
- **Fix timeline**: Varies by severity; critical issues prioritized

## Scope

Vulnerabilities in the core kernel code, boot process, and local-first data handling are in scope. Third-party dependencies are covered by their respective security policies.
